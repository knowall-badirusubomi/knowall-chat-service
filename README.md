# Knowall Chat Service

Frameworks utilised: Flask, Flask.socketio

## Install dependencies

- Highly recommend you execute in a virtual environment
  > pip install -r requirements.txt

## Provide environment variables

> cp .env-sample.txt .env

## Initiate server

> python src/server.py

### Dependencies

- Redis server [link](https://redis.io/docs/latest/develop/clients/redis-py/)
